## Findings considered and rejected

- **Repository agent-policy files as a product vulnerability** — rejected:
  they are trusted workspace governance in this audit context, not runtime input.
- **High transitive `brace-expansion` advisories under ExcelJS** — not promoted
  to a security plan because no user-controlled brace/glob input was found on a
  reachable export path. Reassess during Plan 012 dependency/package review.
- **Next.js, Vercel, and authentication changes** — rejected as inapplicable:
  this repository is a Node/TypeScript library and CLI, not a web application.
- **PROGRESS test-count wording as a standalone plan** — rejected as low value;
  update counts only alongside the next substantive PROGRESS change, locally if
  the change would otherwise be docs-only.
- **Immediate PUPR division expansion** — deferred until correctness and npm
  release stabilize; extraction fidelity dominates the effort.
- **Global or cross-instance calculator caching** — rejected: caller-supplied
  bundles/HSD make global mutable caches unsafe; Plan 017 stays instance-local.
